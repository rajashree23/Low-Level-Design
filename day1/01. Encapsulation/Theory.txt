Q) What is Encapsulation?

Encapsulation means keeping the object's data private by restricting direct access to its internal state and exposing controlled ways to interact with it.

For example, if I have Account class and it holds "balance" propertiy, it should only be accessed by a getter method or a controlled setter methods like getBalance(), deposit(), withdraw(). Don't add weak setters like setBalance(balance).

Key Idea-
Hide Internal State + control how it is accessed/modified.
